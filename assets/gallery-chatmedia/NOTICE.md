# Notice: assets/gallery-chatmedia

These pictures belong to the chat-media example (`examples/chat-media.mjs`, drawn by `designs/gallery-chatmedia.mjs`).
They are frames from the public demo videos of three open pull requests in
[microsoft/vscode](https://github.com/microsoft/vscode), by Federico Brancasi:

- `read-aloud-strip.png`: [#331859](https://github.com/microsoft/vscode/pull/331859), Read chat responses aloud (the
  mouse cursor was painted out).
- `image-chat-1610.png`, `dog.png`: [#335735](https://github.com/microsoft/vscode/pull/335735), chat: add Microsoft
  MAI image generation. The dog is the image generated in the demo.
- `angry-*.png`, `move-*.png`, `grr.png`: [#338664](https://github.com/microsoft/vscode/pull/338664), pet: teach the
  VS Code pet new moves and reactions from chat, cropped from the editor exactly as it drew them.
- `pet-idle.png`: the VS Code pet's idle pose (Insiders colours), enlarged 8x with nearest neighbour.

The frames show work in progress in open pull requests, not shipped features.
