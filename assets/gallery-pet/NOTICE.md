# Notice: assets/gallery-pet

These pictures belong to the pet-studio example (`examples/pet-studio-example.mjs`, drawn by
`designs/gallery-pet.mjs`). They come from [Pet Studio](https://github.com/federicobrancasi/pet-studio), a
personal fan project by Federico Brancasi. It is not an official Microsoft or Visual Studio Code project.

## The VS Code pet artwork

The pet's artwork belongs to Microsoft. It is published in the
[microsoft/vscode](https://github.com/microsoft/vscode) repository under the MIT License, reproduced below, at
the commit Pet Studio pins:
[src/vs/workbench/contrib/chat/browser/widget/media/chatPet](https://github.com/microsoft/vscode/tree/9c8b8c2bfda213a859cfd5beffb1c0f2724690ed/src/vs/workbench/contrib/chat/browser/widget/media/chatPet).

Every file in this folder is derived from that artwork:

- `px/`: the pet's states and moves, rendered by the Pet Studio kit from the real sprites and enlarged 8x with
  nearest neighbour. The moves (`move-*`) are Pet Studio's ready-made moves, built on the real poses.
- `cw-*.png`, `reel-*.png`, `moves.png`, `review-*.png`: frames and pictures from Pet Studio's documentation
  (`docs/media/`): the Coding World film, the four example reels, the moves montage and a review package.
- `presets/`: the seven sizes of Pet Studio's `ship-it` example image, rendered with the kit.
